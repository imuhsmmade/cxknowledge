# CX Knowledge · معرفة تجربة العميل

مرجع عربي لتجربة العميل: أدوات لتصميم رحلة العميل وتقييمها، ودروس عملية، وموسوعة ومؤشرات ومعايير، وأخبار ومبادرات من 193 دولة.

موقع ثابت (HTML/CSS/JS) يُنشر على GitHub Pages، وتُحدَّث أخباره آلياً كل 15 دقيقة تقريباً، وتحليلاته المحررة مرتين يومياً.

## بنية الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | هيكل الموقع؛ التنقل بين الصفحات عبر روابط `#/...` |
| `assets/app.js` | الصفحات: الرئيسية، الدول، ملف الدولة، المستجدات، المؤشرات، المبادرات، تصميم الرحلة، المنهجية |
| `assets/lab.js` | أدوات الرحلة: الرسم وكشف نقاط الانكسار، المحاكاة، الحاسبات، تقييم النضج، المنهجية، المكتبة والقوالب |
| `data/news.js` | المستجدات — **يحدّثها التشغيل المجدول** |
| `data/indices.js` | المؤشرات وآخر قراءاتها |
| `data/profiles.js` | الملفات المعمقة للدول (الجهات، الأرقام، المبادرات) |
| `data/countries.js` | أسماء الدول ودرجات EGDI 2024 والإقليم |
| `data/library.js` | المنهجية، مكتبة الرحلات، المصطلحات، النماذج |
| `assets/stations.js` | دورة العمل: تعريف المحطات وصفحاتها، وتحديد المحطة النشطة لكل رابط |
| `data/lessons.js`، `assets/lessons.js` | الدروس العملية وحاسباتها |
| `data/model.js` | نموذج «وُصول» لتصميم الرحلة وتقييمها، ومنهجيات تصميم الرحلة |
| `data/metricx.js` | أنواع المؤشرات، وخطوات الحساب، والأمثلة المحلولة، ومنهجيات المؤشرات الدولية |
| `data/shelf.js` | المكتبة: الكتب والبودكاست |
| `data/glossary.js` | معجم المصطلحات المصنف |
| `assets/model.js` | صفحات النموذج والمنهجيات والمكتبة |
| `data/world.json` | حدود الدول (TopoJSON مبسّط من world-atlas) |
| `templates/*.csv` | قوالب قابلة للتنزيل |
| `scripts/validate.js` | فحص البيانات قبل النشر |

## روابط الصفحات

- دورة العمل: `#/understand` افهم · `#/design` صمّم · `#/measure` قِس · `#/improve` حسّن · `#/world` العالم
- الدروس العملية: `#/learn/lessons` و`#/learn/lessons/<id>` (البيانات في `data/lessons.js`)

- `#/` الرئيسية · `#/countries` الدول · `#/country/sa` ملف دولة (رمز ISO من حرفين)
- `#/news` المستجدات · `#/item/<id>` مادة محددة
- `#/indices` · `#/initiatives` · `#/library` (`/books`، `/podcasts`) · `#/learn/model` · `#/learn/approaches` · `#/learn/metrics` · `#/about`
- أدوات التقييم كلها لا تعرض النتيجة إلا بعد ضغط زر التقييم.

## قواعد المحتوى

- كل رقم من مصدره مباشرة، ولكل مادة رابط وتاريخ نشر.
- الملخصات بالعربية الفصحى بجمل خبرية مباشرة؛ المصطلح الإنجليزي بين قوسين عند أول ذكر.
- المواد الإنجليزية `lang: "en"` وتظهر بوسم «مترجم».

## الفحص قبل الدفع

```
node scripts/validate.js
```
