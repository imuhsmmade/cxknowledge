# CX Knowledge · معرفة تجربة العميل

أطلس عربي لتجربة العميل: أخبار ودراسات ومؤشرات ومبادرات من 193 دولة، وقسم لتصميم رحلة العميل (منهجية، أداة رسم، مكتبة رحلات، قوالب ومصطلحات).

موقع ثابت (HTML/CSS/JS) يُنشر على GitHub Pages، ويُحدَّث محتواه آلياً مرتين يومياً.

## بنية الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | هيكل الموقع؛ التنقل بين الصفحات عبر روابط `#/...` |
| `assets/app.js` | الصفحات: الرئيسية، الأطلس، ملف الدولة، المستجدات، المؤشرات، المبادرات، تصميم الرحلة، المنهجية |
| `assets/lab.js` | أداة رسم الرحلة (حفظ في المتصفح، تصدير PNG وJSON، طباعة) |
| `data/news.js` | المستجدات — **يحدّثها التشغيل المجدول** |
| `data/indices.js` | المؤشرات وآخر قراءاتها |
| `data/profiles.js` | الملفات المعمقة للدول (الجهات، الأرقام، المبادرات) |
| `data/countries.js` | أسماء الدول ودرجات EGDI 2024 والإقليم |
| `data/library.js` | المنهجية، مكتبة الرحلات، المصطلحات، النماذج |
| `data/world.json` | حدود الدول (TopoJSON مبسّط من world-atlas) |
| `templates/*.csv` | قوالب قابلة للتنزيل |
| `scripts/validate.js` | فحص البيانات قبل النشر |

## روابط الصفحات

- `#/` الرئيسية · `#/atlas` الأطلس · `#/country/sa` ملف دولة (رمز ISO من حرفين)
- `#/news` المستجدات · `#/item/<id>` مادة محددة
- `#/indices` · `#/initiatives` · `#/journey/method|tool|library|kit` · `#/about`

## قواعد المحتوى

- كل رقم من مصدره مباشرة، ولكل مادة رابط وتاريخ نشر.
- الملخصات بالعربية الفصحى بجمل خبرية مباشرة؛ المصطلح الإنجليزي بين قوسين عند أول ذكر.
- المواد الإنجليزية `lang: "en"` وتظهر بوسم «مترجم».

## الفحص قبل الدفع

```
node scripts/validate.js
```
